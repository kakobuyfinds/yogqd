What to check before ordering

FansBuy finds and original product links

When browsing Weidian finds, Taobao listings or 1688 products, record the original product link and seller item ID. Open the listing again before ordering and match the selected size, color and seller. For clothing sets, confirm exactly which pieces are included.

Sneaker sizing and clothing measurements

Compare your foot length with the seller’s sneaker size chart. If you request an insole measurement photo, compare it with a pair you already wear. For a hoodie or T-shirt, match the flat chest width and body length. For pants, check the flat waist and inseam. For a jacket, leave room for the layers you plan to wear.

FansBuy QC photos and warehouse checks

Compare warehouse QC photos with the selected variant. Ask for an outsole close-up for sneakers, a zipper detail for jackets, and a straight-on view of jersey print placement. For a cap or necklace, check the closure or clasp. If there is a mismatch, check the seller’s return window while the item is still at the warehouse.

FansBuy shipping estimate by destination

Use the actual destination country and postal code when comparing international shipping quotes for the US, UK, Canada or Australia. Check parcel dimensions, actual weight and volumetric weight. If you consolidate parcels, request a new quote using the final packed dimensions and check any applicable duties or taxes.

FansBuy spreadsheet FAQ

What is a FansBuy spreadsheet?

A FansBuy spreadsheet is a directory of product finds that helps shoppers compare listings and locate seller links before placing an order through a shopping agent.

Where do the category links go?

The category links open the matching collections on HipoBuyFind. Check the original seller link and confirm that your chosen agent can open it before ordering.

Do QC photos prove authenticity?

QC photos show visible details such as condition, color and stitching. Use purchase documentation or a qualified authentication service if you need to verify authenticity.

How can I estimate the full delivered cost?

Add the item price, domestic delivery, agent fees and international shipping. Check currency conversion, any applicable import charges and how your shipping line calculates billable weight.
